# Jerusalem Projects Index

Projects tied to Jerusalem as a place — the city, its streets, its municipal
services and specific addresses within it.

A sub-index of
[Israel-Projects-Index](https://github.com/danielrosehill/Israel-Projects-Index),
which links here. Small by design: most Israel-related work belongs there or in
a narrower topic index, and this one exists for the handful of projects whose
subject is Jerusalem specifically rather than Israel generally.

## Scope

**In:** projects whose subject is Jerusalem itself — city streets and public
space, Jerusalem municipal services and reporting channels, specific Jerusalem
addresses, neighbourhood or local-area reference material.

**Out:** projects that are Israel-focused but not Jerusalem-specific (national
datasets, Israeli telecoms, Israeli AI tooling); projects that merely happen to
have been written in Jerusalem. Where a repo fits both this index and a narrower
topic index, the narrower one wins and this is a cross-reference.
